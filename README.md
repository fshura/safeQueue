# SafeQueue

Потокобезопасная очередь на C++ с использованием мьютексов и условных переменных.

## Возможности

- Потокобезопасное добавление элементов (push)
- Потокобезопасное извлечение с ожиданием (pop)
- Non-blocking попытка извлечения (try_pop)
- Проверка на пустоту и размер очереди
- **Move-семантика** для эффективной работы с большими объектами
- Поддержка любых типов данных (шаблонный класс)

## Тестирование

Проект покрыт юнит-тестами с использованием **Google Test**. Тесты проверяют:

| Тест | Описание |
|------|----------|
| `PushPop` | Базовая операция добавления/извлечения |
| `FIFO` | Сохранение порядка элементов (первый пришёл — первый ушёл) |
| `Empty` | Корректная работа метода empty() |
| `Size` | Точное отслеживание количества элементов |
| `TryPopOnEmpty` | Попытка извлечения из пустой очереди возвращает false |
| `TryPopOnNonEmpty` | Успешное извлечение через try_pop |
| `TwoAdderThreeSumDel` | Многопоточный сценарий: 2 производителя и 3 потребителя |

## Сборка

### Требования

- C++17
- CMake 3.10+
- Google Test (для тестов)
- pthread

### Сборка основной программы

```bash
mkdir build && cd build
cmake ..
make
./safeQueue```

### Сборка и запуск тестов

```bash
mkdir build && cd build
cmake .. -DBUILD_TESTS=ON
make
./run_tests```
